

## Controls

V: Toggle Visualization-Only mode (hides parameter bars, preset labels, and settings text)
1 / 2: Switch Studio 54 vs. Techno Pumper preset
Up / Down: Adjust Flight Perspective (0.00 – 1.00)
Q / A: Adjust Sub -> Body Duck weight
W / S: Adjust Kick -> Body Duck weight
E / D: Adjust Air Width
M: Toggle Monitor Output (mute/unmute speaker playback of the processed stream)
